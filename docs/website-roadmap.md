# Aimakox Website Roadmap

> The website is a continuously evolving manufacturing AI knowledge system.
> Not a static brochure. Not a marketing site. A deployment archive and intelligence layer.

---

## Operating Model

```
Claude Code → local edits → git commit → git push → Vercel auto-deploy → Cloudflare delivery
```

Every commit is a knowledge update. Every page is a living document.
